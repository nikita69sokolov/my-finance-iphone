# Мои Финансы — финансовый кабинет для iPhone

Локальное веб-приложение (PWA), которое можно установить на главный экран iPhone через Safari. Без серверной базы данных, рекламы и аналитики. Для чтения PDF используется размещённый в этом репозитории Mozilla PDF.js.

## Возможности

- Добавление, редактирование и удаление расходов, доходов и переводов.
- Учёт по месяцам, аналитика категорий и поиск операций.
- Месячные лимиты по категориям.
- Учёт кредитов: остаток, ставка, платёж, ориентировочный срок погашения.
- Локальный импорт PDF-выписок Сбербанка с проверкой результата перед сохранением (экспериментальная функция).
- Импорт CSV-выписок с выбором колонок, поддержкой UTF-8 и Windows-1251, разделителей `;`, `,` и Tab.
- Зашифрованная резервная копия (AES-256-GCM + PBKDF2) и восстановление.
- Работа офлайн после первой загрузки благодаря Service Worker.

## Публикация через GitHub Pages

1. Создайте публичный репозиторий `my-finance-iphone` в своём аккаунте GitHub. Не добавляйте туда личные выписки или резервные копии.
2. Загрузите в корень репозитория файлы проекта (не ZIP-архив).
3. В GitHub откройте **Settings → Pages → Build and deployment → Deploy from a branch** и выберите `main` и `/(root)`.
4. Откройте `https://USERNAME.github.io/my-finance-iphone/` на iPhone в Safari, нажмите **Поделиться → На экран Домой**, включите **Открывать как веб-приложение**.

Для GitHub Free Pages проект должен находиться в публичном репозитории. Код не содержит никаких личных финансовых сведений.

## Конфиденциальность

Все операции, кредиты и бюджеты хранятся в браузерной базе IndexedDB на устройстве. Сведения не загружаются в GitHub или банки. GitHub Pages обслуживает только статические файлы приложения. Данные локального хранилища могут быть удалены системой или пользователем; обязательно делайте резервные копии. Зашифрованные резервные файлы сохраняйте отдельно, пароль восстановить нельзя.

**Ограничения:** это не нативное iOS-приложение, а PWA. Прямой обмен с банками и импорт XLSX пока отсутствуют. При импорте операции с одинаковой датой, названием, суммой и счётом считаются возможными дубликатами и пропускаются; проверяйте итог. Автоматический расчёт кредитов — приблизительный и не учитывает все условия договора.

## Разработка

Проект использует только HTML/CSS/JavaScript, не требует сборки, Node.js и установки зависимостей. Главные файлы: `index.html`, `styles.css`, `app.js`, `sw.js`, `manifest.webmanifest`, `icon-192.png`, `icon-512.png`, `icon.svg`.

## Сбербанк: только чтение (v1.1)

1. В официальном СберБанк Онлайн закажите «Выписку по дебетовой карте» или счёту в разделе «Выписки и справки».
2. Сохраните PDF в «Файлы» на iPhone.
3. В приложении «Мои Финансы» откройте «Настройки» → «Сбербанк · только чтение» → «Загрузить PDF Сбербанка».
4. Проверьте даты, суммы, направления и названия операций в предварительном просмотре; только затем импортируйте.

**Нет банковской авторизации.** Приложение не принимает и не хранит логин, пароль, SMS или банковский токен. Оно не имеет функций управления банковским счётом, платежей или переводов. Файл читается локально на устройстве, без отправки в облачные конвертеры. Библиотека PDF.js версии 5.7.284 расположена в `vendor/` (лицензия Apache-2.0) и загружается с того же сайта; исполнение встроенного в PDF кода отключено. Не добавляйте настоящие выписки в публичный репозиторий. Для следующего обновления истории необходимо скачать новую выписку вручную.

**Ограничения PDF:** парсер пока не проверен на всех актуальных формах Сбербанка; возможны неверные или отсутствующие операции. Сканированные PDF без текстового слоя не поддерживаются. Проверяйте результат с оригинальной выпиской, прежде чем подтверждать импорт.
