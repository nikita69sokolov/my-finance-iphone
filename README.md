## v1.4 — импорт реальных PDF и сбережения

- Локальное чтение Сбер PDF с полной сверкой всех операций по банковским итогам. При несовпадениях интерфейс предупреждает пользователя.
- Распознавание ипотечного графика из таблицы, включая полный план основного долга, процентов, платежей и расчётных остатков. ПСК не используется вместо процентной ставки.
- Новая вкладка «Вклад»: учёт подтверждённого остатка, даты, ставки и движения между картой и накоплениями. Неподтверждённый остаток не выдумывается.
- Повторный импорт не дублирует известные операции; замена предыдущего старого PDF-импорта требует явного подтверждения.
- Нет сетевого обмена банковскими данными, платежей или прямого доступа к счетам. Все личные PDF остаются только на устройстве пользователя.

# Мои Финансы — финансовый кабинет для iPhone

Локальное веб-приложение (PWA), которое можно установить на главный экран iPhone через Safari. Без серверной базы данных, рекламы и аналитики. Для чтения PDF используется локальная копия открытой библиотеки Mozilla PDF.js (Apache-2.0).

## Возможности

- Добавление, редактирование и удаление расходов, доходов и переводов.
- Учёт по месяцам, аналитика категорий и поиск операций.
- Месячные лимиты по категориям.
- Учёт кредитов: остаток, ставка, платёж, ориентировочный срок погашения.
- Импорт текстовых PDF-выписок Сбербанка непосредственно на устройстве через локально размещённый Mozilla PDF.js. Проверка операций перед подтверждением.
- Импорт CSV-выписок с выбором колонок, поддержкой UTF-8 и Windows-1251, разделителей `;`, `,` и Tab.
- Зашифрованная резервная копия (AES-256-GCM + PBKDF2) и восстановление.
- Работа офлайн после первой загрузки благодаря Service Worker.

## Публикация через GitHub Pages

1. Создайте публичный репозиторий `my-finance-iphone` в своём аккаунте GitHub. Не добавляйте туда личные выписки или резервные копии.
2. Загрузите в корень репозитория файлы проекта (не ZIP-архив).
3. В GitHub откройте **Settings → Pages → Build and deployment → Deploy from a branch** и выберите `main` и `/(root)`.
4. Откройте `https://USERNAME.github.io/my-finance-iphone/` на iPhone в Safari, нажмите **Поделиться → На экран Домой**, включите **Открывать как веб-приложение**.

Для GitHub Free Pages проект должен находиться в публичном репозитории. Код не содержит никаких личных финансовых сведений.

## Конфиденциальность

Все операции, кредиты и бюджеты хранятся в браузерной базе IndexedDB на устройстве. Сведения не загружаются в GitHub или банки. GitHub Pages обслуживает только статические файлы приложения. Данные локального хранилища могут быть удалены системой или пользователем; обязательно делайте резервные копии. Зашифрованные резервные файлы сохраняйте отдельно, пароль восстановить нельзя.

**Безопасность Сбербанка:** прямого подключения к личному счёту нет. Приложение не принимает и не хранит логины/пароли/СМС-коды банка, не имеет платежных API, обрабатывает выбранный PDF локально, без загрузки выписки на сервер. Требуется скачивать новую выписку в СберБанк Онлайн. Парсер PDF экспериментальный: некоторые шаблоны и сканированные PDF не распознаются. Любые результаты нужно сверять перед импортом.

**Ограничения:** это не нативное iOS-приложение, а PWA. Прямой обмен с банками и импорт XLSX пока отсутствуют. При импорте операции с одинаковой датой, названием, суммой и счётом считаются возможными дубликатами и пропускаются; проверяйте итог. Автоматический расчёт кредитов — приблизительный и не учитывает все условия договора.

## Разработка

Проект использует только HTML/CSS/JavaScript, не требует сборки, Node.js и установки зависимостей. Главные файлы: `index.html`, `styles.css`, `app.js`, `sw.js`, `manifest.webmanifest`, `icon-192.png`, `icon-512.png`, `icon.svg`.

## Импорт PDF Сбербанка (v1.1)

1. В официальном СберБанк Онлайн откройте «Выписки и справки», сформируйте выписку по карте/счёту и сохраните PDF в «Файлы».
2. В приложении «Мои Финансы» откройте «Настройки» → «Сбербанк · только чтение» → «Загрузить PDF Сбербанка».
3. Проверьте сопоставление полей, предварительный просмотр дат, сумм и типа, нажмите «Импортировать».
4. Следующую выписку можно импортировать тем же способом — совпавшие операции не будут повторяться.

Для парсинга применяется `pdfjs-dist@5.7.284` с запрещённым исполнением JavaScript внутри PDF (`isEvalSupported: false`). Файлы библиотеки копируются в `vendor/` с помощью одноразового GitHub Actions workflow. Не добавляйте личные выписки, банковские токены и резервные копии в публичный репозиторий.

## v1.2 — Кредиты, ипотека и подписки

- Кредиты: вид обязательства, банк, дата следующего планового платежа, остаток, ставка, приблизительная оценка срока и процентов. Остаток по банку обновляется вручную: не снижается автоматически при наступлении даты.
- Подписки: цена за период, ежемесячный эквивалент, годовая оценка, ожидаемая дата списания, статус, ручное добавление и удаление.
- Приложение **предлагает** кандидатов по повторным операциям в уже импортированных выписках: по похожему названию, сумме и интервалам. Ничего не заносит в список без подтверждения пользователя. Найденные повторения не гарантируют наличие подписки.
- Нет доступа к Apple ID, подпискам других приложений, банковским счетам, переводам или платежам. Для точного перечня Apple: «Настройки» → имя → «Подписки».
- Плановые платежи не включаются повторно в фактические расходы. При восстановлении старых зашифрованных резервных копий поле подписок создаётся пустым, ранее записанные кредиты и операции сохраняются.


## v1.3 — импорт кредитов и ипотеки из документов Сбербанка

В разделе «Кредиты» нажмите «Распознать кредит из PDF Сбербанка» и выберите сохранённый на iPhone график платежей или справку о задолженности. Локальный PDF.js извлекает найденные значения: остаток **основного** долга (только по явной метке), ставку, платёж, дату платежа и дату справки. Перед записью в память пользователь подтверждает поля, создаёт новый кредит либо обновляет существующий. Отсутствующие поля при обновлении сохраняют прежние значения. Первоначальная сумма кредита и общая задолженность с процентами не подставляются в поле остатка.

**Ограничения:** распознавание эвристическое, тестовые шаблоны не покрывают все формы Сбера. Без подтверждения документ не меняет данные. Сканированные PDF без текстового слоя не поддерживаются. Файл PDF не покидает устройство и не записывается в GitHub. Платежи приложение не совершает. Если PDF содержит несколько разных кредитов, выбирайте отдельную справку по конкретному договору и проверяйте результат.
